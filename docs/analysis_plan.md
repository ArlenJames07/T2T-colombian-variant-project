# Analysis plan

1. Characterize the cohort-wide T2T structural-variant landscape and caller
   concordance.
2. Quantify methylation changes at SV breakpoints and disease-associated loci,
   stratified by haplotype and molecular mechanism.
3. Evaluate relationships between structural variation, methylation, and 3D
   genome annotations.
4. Build machine-learning tables only from frozen, versioned master tables;
   split data by sample before feature selection or model fitting.

Completed outputs are linked under `results/`, `figures/`, and `reports/`.
Analysis-specific scripts or notebooks should be added to the matching numbered
directory without modifying primary pipeline outputs.
